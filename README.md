# module-12-smart-app
mart Text Analyzer & Live Data App
About the Project

This is a simple Python project created as a learning assignment. It combines text analysis, number sorting, and live weather data using an API. The goal is to practice basic Python programming, logic building, and API usage.

Features
Text Analyzer
Counts total characters in a sentence
Counts total words
Checks if the sentence is a palindrome (ignores spaces)
Sorting Tool
Takes numbers as input from user
Sorts numbers in ascending order
Sorts numbers in descending order
Finds largest number without using max()
Finds smallest number without using min()
Live Data Viewer
Shows real-time weather information
Gets temperature of any city using API
Uses internet data (wttr.in API)
Technologies Used
Python 3
Requests library
wttr.in API
